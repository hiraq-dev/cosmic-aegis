# Space Apps submission checklist
- [ ] Project name + summary (50-200 words, max 1500 chars)
- [ ] Demo: max 7 slides OR max 30 s video, public link, no login (required for Global Award)
- [ ] Project link (public GitHub repo)
- [ ] Project details (what/how/benefit/tools/creativity)
- [ ] SI-use disclosure: acknowledge AI-generated code in README/metadata; watermark AI images; no NASA logos
- [ ] NASA data/resources used (required for Global Award), full URLs
- [ ] Partner/other data and open-source resources listed (CSA, models, libraries)
